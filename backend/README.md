План действий

## 1. Сделать список категорий нормальным

Сейчас Django показывает базовый CRUD. Например, хотим:

Категории
────────────────────────────────
Название        Активна
────────────────────────────────
Стрижки         ✓
Маникюр         ✓
Косметология    ✗

Добавим:

list_display
list_filter
search_fields
сортировку.

## 2. Сделать так же услуги

Чтобы в списке было:

Название | Категория | Цена | Длительность | Активна

И можно было фильтровать по категории/активности и искать по названию.

## 3. Самое интересное — специалисты

Сделаем возможность прямо в специалисте выбирать услуги:

Специалист
├── ФИО
├── Специализация
├── Фото
├── Активен
└── Услуги
    ☑ Чистка лица
    ☑ Пилинг
    ☑ Массаж лица


## 4. Расписание

Сделаем нормальный интерфейс для:

Специалист → Расписание

и добавим расписание прямо на странице специалиста через Inline. То есть не надо отдельно заходить в SpecialistSchedule.
