# Сайт косметологии Style72

## Требования

* **Python 3.12**
* Установленный **`pip`**
* **Docker** и **Docker Compose** — опционально, для запуска в контейнере

## Структура проекта

```text
project/
├── frontend/        # Фронтенд
├── backend/         # Бэкенд
├── requirements.txt
└── main.py
```

## Быстрый запуск

### Вариант 1. Локальный запуск без Docker

#### 1. Создайте и активируйте виртуальное окружение

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**

```bash
python3.12 -m venv venv
source venv/bin/activate
```

#### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

#### 3. Инициализируйте проект

Выполните:

```bash
python manage.py setup
```

Команда автоматически:

* применит миграции базы данных;
* соберёт статические файлы;
* создаст аккаунт администратора.

Данные администратора по умолчанию:

```text
Логин: admin
Пароль: admin
```

#### 4. Запустите приложение

```bash
python main.py
```

После запуска веб-страница автоматически откроется в браузере.

> **Примечание:** при локальном запуске перед каждым стартом приложения необходимо активировать виртуальное окружение `venv`.

---

## Вариант 2. Запуск через Docker

Если на компьютере установлен Docker, проект и база данных можно запустить одной командой без ручной настройки Python и виртуального окружения.

### 1. Запустите контейнеры

```bash
docker-compose up --build
```

При запуске контейнер автоматически:

* выполнит все миграции;
* соберёт статические файлы;
* создаст суперпользователя.

### 2. Админ-панель

После запуска админ-панель доступна по адресу:

**[http://localhost:8000/admin/](http://localhost:8000/admin/)**

Данные для входа:

```text
Логин: admin
Пароль: admin
```

Пароль также можно изменить через переменную:

```text
DJANGO_SUPERUSER_PASSWORD
```

в `docker-compose.yml`.

---

## Полная пересборка базы данных

Если требуется полностью пересоздать базу данных в Docker, выполните:

```bash
docker-compose down -v
```

Затем снова запустите проект:

```bash
docker-compose up --build
```

> ⚠️ Команда `docker-compose down -v` удаляет тома, поэтому данные базы данных будут потеряны. Используйте её только при необходимости полной пересборки.

## Кратко

| Способ                | Команда запуска                |
| --------------------- | ------------------------------ |
| Локально              | `python main.py`               |
| Docker                | `docker-compose up --build`    |
| Инициализация проекта | `python manage.py setup`       |
| Полная очистка Docker | `docker-compose down -v`       |
| Админ-панель          | `http://localhost:8000/admin/` |
